Sudoku is a logic-based number placement puzzle. No math required—just pure focus.

The Three Golden Rules

To win, fill the 9x9 grid so that every row, column, and 3x3 box contains all digits from 1 to 9. A move is incorrect if you violate any of these rules:

1

Rows

No row can contain duplicate numbers. Each row must have exactly one of every number from 1 to 9.

2

Columns

No column can contain duplicate numbers. Each vertical column needs every digit from 1 to 9 exactly once.

3

3x3 Grids

The main board is divided into nine 3x3 squares. Each of these smaller squares must also contain 1 through 9.

Pro Tips for Beginners

Tip 1 The Low-Hanging Fruit

Look for rows, columns, or 3x3 sections that already have 5 or more numbers filled in. Try placing the missing numbers in the empty cells. By using the process of elimination, you will often find spots where only one specific number can logically fit.

Tip 2 Visual Scanning

Visually break the board into 3 large columns and 3 large rows. If two 3x3 boxes in a row already have the same number, the third box in that row must also contain it. Check the intersecting columns to find its exact location.
